# DenuvoNetCredDecrypter: безопасная альтернатива для получения учётных данных офлайн-активации

> **Скачать последнюю версию:** [Releases](https://github.com/kr1pt0-y4dr0/denuvo_net_creddecrypter/releases/latest)

## Зачем нужна эта утилита

**DenuvoNetCredDecrypter** — это небольшая консольная утилита для Windows, которая решает одну конкретную задачу: **получить логин и пароль для офлайн-активации игры** через сервис `denuvo.net`, не запуская при этом оригинальный активатор `DenuvoNet_launcher.exe`.

Оригинальный лаунчер от `denuvo.net` — это проприетарное, обфусцированное приложение, которое требует прав администратора, блокирует ввод, завершает процессы и может выполнять множество действий, не описанных в инструкции для пользователя. Для многих пользователей такие условия неприемлемы, особенно с учётом того, что лаунчер не является открытым и был проанализирован как **потенциально нежелательное ПО (PUA/riskware)** с признаками трояна-загрузчика.

`DenuvoNetCredDecrypter` выполняет ту же функцию получения учётных данных, но **не требует прав администратора, не блокирует систему, не завершает процессы и не выполняет скрытых действий**. Утилита использует тот же алгоритм, что и оригинальный лаунчер, но реализует его в прозрачном, читаемом виде.

## Риски оригинального активатора `DenuvoNet_launcher.exe`

Согласно независимому анализу (см. приложенный `REPORT.md`), оригинальный активатор обладает следующими характеристиками:

### 1. Обфускация и сокрытие логики
Приложение обфусцировано **.NET Reactor** — строки зашифрованы, тела методов скрыты, используется JIT-хук, control-flow flattening и анти-отладка. Это делает невозможным аудит кода без специальных инструментов и создаёт предпосылки для скрытого вредоносного поведения.

### 2. Требование прав администратора
Запуск от имени администратора даёт приложению полный доступ к системе: файлам, реестру, процессам и сетевым настройкам. Пользователь не может контролировать, что именно делает программа.

### 3. Блокировка компьютера и завершение процессов
Лаунчер содержит метод `DoCheaterskiller`, который **принудительно завершает процессы**, содержащие в имени подстроки:
```
note, cheat, cheatengine, wireshark, tcpdump, HTTPDebuggerSvc, HTTPDebuggerUI
```
Это означает, что блокируются не только «читы», но и **любые программы для анализа трафика и отладки**, а также, например, `notepad.exe`. Лаунчер может заблокировать работу пользователя без предупреждения.

### 4. Работа с чужими учётными данными
Лаунчер получает с сервера **логин и пароль от чужого аккаунта** (Steam, Epic, Ubisoft, EA, Microsoft Store), расшифровывает пароль с помощью **жёстко зашитого ключа** `SHA256("voron2020")` и автоматически вводит его в клиент магазина через AutoHotkey. Это означает:
- Пароль передаётся по сети и хранится в памяти процесса.
- Схема шифрования слабая (общий ключ для всех паролей, нулевой IV).
- Лаунчер может изменять реестр Steam, файлы `loginusers.vdf`, настройки клиентов и даже **отключать сеть** (для Ubisoft).

### 5. Самообновление без проверки подписи
Лаунчер скачивает `update.xml` и `DenuvoNet_launcher.zip` с сервера **по HTTP** (не HTTPS) и запускает обновление **без проверки цифровой подписи или хеша**. Это создаёт риск подмены обновления (MITM) и выполнения произвольного кода.

### 6. Обход проверки TLS-сертификатов
В коде лаунчера присутствует **принятие любого сертификата** (`ServerCertificateValidationCallback => true`), что делает HTTPS-соединения уязвимыми для перехвата.

### 7. Отключение защитных механизмов
Лаунчер изменяет системные сертификаты, правит реестр и может влиять на работу антивирусных и аналитических инструментов.

### 8. Отсутствие прозрачности
Пользователь не может узнать, какие именно данные отправляются на сервер, какие файлы создаются и изменяются, и какие процессы завершаются. Всё это скрыто за обфускацией и не документировано.

| **Автоматический ввод пароля** | Да (через AutoHotkey) | **Нет** (пароль просто сохраняется в файл) |
| **Самообновление** | Да (HTTP, без подписи) | **Нет** |
| **Обход TLS** | Да | **Нет** (используется стандартная проверка сертификатов) |

Она не вмешивается в работу системы, не требует административных прав и не выполняет скрытых действий. Пользователь получает логин и пароль и может самостоятельно решить, как их использовать.

## Как работает утилита

1. **Определение HWID.** Утилита вычисляет HWID по той же формуле, что и оригинальный лаунчер: `MD5(cpuId + baseId)`, где `cpuId` берётся из `Win32_Processor.ProcessorId`, а `baseId` — из `Win32_BaseBoard`.
2. **Ввод данных.** Пользователь вводит три строки: ID (ключ активации), HWID (можно использовать автоматически определённый) и информацию о железе (можно оставить пустой или указать произвольно).
3. **Запрос к API.** Сначала утилита проверяет доступность учётных данных (`checkAccount`: `login`, `hwid`, `pc`), и только при `success: true` запрашивает их выдачу (`reqcreds`: `login`, `hwid`). Оба запроса — POST на `https://games-launcher.top/api.php`, User-Agent — `Games-launcher413`, как в оригинале.
4. **Расшифровка пароля.** Полученный `auth_pswd` (Base64) расшифровывается алгоритмом **AES-256-CBC** с ключом `SHA256(UTF8("voron2020"))`, IV из 16 нулевых байт, с отбрасыванием первого байта (маркера).
5. **Сохранение.** Логин, пароль, HWID и информация о железе сохраняются в текстовый файл с именем, равным введённому ID.

Утилита **не**:
- запускает Steam, Epic, Ubisoft, EA или Microsoft Store;
- вводит пароль в какие-либо окна;
- завершает процессы;
- изменяет реестр или файлы клиентов;
- скачивает обновления;
- обходит проверку TLS.

## Использование

### Сборка
```powershell
dotnet build DenuvoNetCredDecrypter.sln -c Release
```

### Запуск
```powershell
.\src\DenuvoNetCredDecrypter\bin\Release\net472\DenuvoNetCredDecrypter.exe
```

Программа полностью интерактивна и не принимает аргументов командной строки.

### Конфигурация
Файл `appsettings.json` рядом с исполняемым файлом:

| Ключ | Назначение |
|---|---|
| `apiUrl` | URL API-эндпоинта (по умолчанию `https://games-launcher.top/api.php`) |
| `userAgent` | User-Agent для запроса (по умолчанию `Games-launcher413`) |
| `aesKeySeed` | Строка, SHA-256 которой используется как ключ AES (по умолчанию `voron2020`) |

## Важное предупреждение

Утилита предназначена **исключительно для исследовательских целей** и для пользователей, которые уже приобрели доступ к офлайн-активации через `denuvo.net` и хотят получить свои учётные данные без запуска небезопасного оригинального лаунчера.

**Не используйте утилиту для доступа к аккаунтам, которые вам не принадлежат.** Полученные логин и пароль предназначены для офлайн-активации игры, купленной у продавца. Использование чужих учётных данных без разрешения является нарушением закона.
